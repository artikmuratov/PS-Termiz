## O'qitish ritmi (2 kunlik tizim)

Har bir mavzu 2 ta 45 daqiqalik darsda o'tiladi:
1. **1-kun (Asosiy dars — `dars-rejasi.md`):**
   - `0–5 daqiqa`: Qizdirish (tezkor savollar)
   - `5–15 daqiqa`: Qisqa nazariya (hayotiy o'xshatishlar bilan)
   - `15–37 daqiqa`: Amaliyot ("Men yozaman — biz yozamiz — sen yozasan")
   - `37–42 daqiqa`: "Xato ovchisi" / mini-o'yin
   - `42–45 daqiqa`: Yakun
2. **2-kun (Mustahkamlash darsi — `amaliy-dars-rejasi.md`):**
   - Yangi nazariyasiz to'liq 45 daqiqalik amaliyot: **"Tayyor misol (Namuna) → Sening varianting"** uslubida 3 darajali topshiriqlar (`starter.html`) va xatolarni tuzatish (`xatoni-top.html`).
